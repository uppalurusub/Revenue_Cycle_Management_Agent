# Healthcare Revenue Cycle Management Agent

A modern **React JS with TypeScript** frontend application for processing healthcare insurance claims using an AI-driven Revenue Cycle Management workflow.

The application submits healthcare claim information to a FastAPI backend and presents structured results from multiple specialized agents:

* Claims Agent
* Billing Agent
* Validation Agent

The user interface provides claim intake, API integration, financial metrics, workflow status, agent summaries, validation results, and final recommendations.

---

## Overview

The **Healthcare Revenue Cycle Management Agent** provides a frontend interface for an AI-powered healthcare claim processing workflow.

Users can enter or modify patient, insurance, provider, diagnosis, procedure, and claim information before submitting the claim to the Revenue Cycle Management API.

The backend processes the claim through multiple AI agents and returns structured analysis covering:

* Claim readiness
* Claim confidence
* Billing review
* Estimated reimbursement
* Revenue leakage risk
* Claim validation
* Compliance status
* Workflow risk
* Agent-generated summaries
* Final recommendations

  processing_time_seconds: number;

  agent_outputs: AgentOutputs;

    service_date: string;

}

## CORS Configuration

The FastAPI backend must allow requests from the React development server.

Example FastAPI CORS configuration:

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:5173",
        "http://127.0.0.1:5173"
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

For development environments only, CORS may be configured as:

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

Production environments should use explicitly configured trusted origins.

## API Connection Error

If the application displays:

```text
Unable to connect to
http://127.0.0.1:8000/revenue-cycle/process-claim.
Verify the FastAPI service and CORS configuration.
```

Verify the following:

1. The FastAPI application is running.
2. FastAPI is listening on port `8000`.
3. The `/revenue-cycle/process-claim` router is registered.
4. The React application can access `127.0.0.1`.
5. FastAPI CORS middleware is configured.
6. The request model matches the backend Pydantic model.
7. No firewall or proxy is blocking port `8000`.

Test the backend using:

```text
http://127.0.0.1:8000/docs
```

The Revenue Cycle endpoint should appear in Swagger UI.
